# 今日どこ行く？大阪

カップルや友達と「今日どこ行く？」となったときに、大阪の人気店・穴場を地図で探せるWebアプリです。

- 昼ごはん・夜ごはん・遊びをタブで切り替えて、地図上のピンで表示（時間帯で最初のタブが自動で決まります）
- 「おまかせで3つ選ぶ」で、いま見ている範囲からランダムに3つ提案
- ピンをタップして「♡ 行きたい」で行きたいリストに保存
- 「＋ピンを追加」で、自分で行きたい場所を地図に追加（インスタやお店のURLも保存できます）

## お店の選び方

`scripts/discover-picks.mjs` が Google Places API で、①梅田・難波などの繁華街をエリア名で検索し（`config/areas.json`）、②大阪府全体をマス目に区切って検索して（`config/grid.json`、市中心部は1.5km・それ以外は3kmのマス）取りこぼしを埋め、次の条件で選びます（`config/filters.json` で変更できます）。

| 区分 | 条件 |
| --- | --- |
| 人気店 | 星4.0以上、口コミ1000件以上 |
| 穴場 | 星4.3以上、口コミ100〜999件 |

ファストフードやチェーン店（同じ店名が3店舗以上、または除外リストにある店）は外します。

Google の規約に合わせて、保存するのは **お店のIDと位置だけ** です。店名・星・口コミ数は選ぶときに使うだけで保存しません。そのため地図は Google マップを使います。府全体の検索は3か月に1回だけ行い、間は `scripts/refresh-locations.mjs` が月2回、保存したお店の位置だけを取り直します（位置は30日以内に更新する決まりのため）。

## 手書きの紹介（編集部おすすめ）

`src/data/editorial.json` に、お店のIDをキーにして書きます。書いた店は「編集部おすすめ」と表示され、タップ時に Google への問い合わせも発生しません。

```json
{
  "ChIJxxxxxxxxxxxxxxxx": {
    "name": "お店の名前",
    "comment": "デート向き。窓側の席がおすすめ。",
    "menu": [{ "name": "看板メニュー", "price": "1,480円" }],
    "checkedAt": "2026年10月",
    "officialUrl": "https://example.com",
    "tiktok": true
  }
}
```

口コミの文章や、公式サイト・Google の写真をそのままコピーするのはNGです。自分の言葉と自分で撮った写真で書いてください。

## 費用について

- 地図の表示：月1万回まで無料
- 府全体の検索（3か月に1回）：1回あたり約2000〜2500回の検索
- 位置の更新（月2回）：お店の数だけ位置を取得。位置だけの取得は毎月の無料枠に収まる想定
- 手書きの紹介がない店をタップしたとき：店名だけを Google から取得（月5000回まで無料）

Google Cloud で予算アラートと上限を設定しておくと安心です。

## はじめかた

1. [Google Cloud](https://console.cloud.google.com/) でプロジェクトを作り、請求先アカウントを登録
2. 「Maps JavaScript API」と「Places API (New)」を有効化
3. APIキーを2つ作る
   - 地図表示用：アプリのURLだけで使えるように「HTTPリファラー」で制限
   - ピックアップ用：「Places API (New)」だけに制限（公開しない）
4. 「マップ管理」でマップIDを作り、地図スタイルで「スポット（POI）」を非表示にして紐づける（他の店のアイコンが消えます）
5. `.env.example` を `.env` にコピーしてキーとマップIDを入れる
6. 実行

```bash
npm install
npm run discover-picks      # 府全体から人気店をピックアップ
npm run refresh-locations   # 保存したお店の位置を取り直す
npm run dev           # http://localhost:5173 で確認
```

どちらも GitHub Actions（`.github/workflows/discover-picks.yml` と `refresh-locations.yml`）で自動実行されます。リポジトリの Secrets に `GOOGLE_PLACES_API_KEY` を登録してください。
